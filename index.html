PROJECT 02RAG · Backend

Context-Grounded Notes QA System

A notes-based RAG system that retrieves relevant Markdown content and generates answers constrained to the retrieved context.

  • Uses semantic chunking, embeddings, and cosine-similarity retrieval.
  • Integrates Nomic Embed Text and Qwen3 (4B) through Ollama.
  • Exposes a FastAPI query endpoint with Pydantic validation and Swagger documentation.
  • Returns an explicit “I don't know” when the notes do not support an answer.
